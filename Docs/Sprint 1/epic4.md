# Epic 4 - Define elapsed-time calculations

## Objective: 
Establish how the game determines how much real-world time has passed.

## Issues

### 4.1 — Define Elapsed-Time Formula
Establish:
End Time − Start Time = Elapsed Time

### 4.2 — Define Calculation Precision
Determine whether elapsed time is calculated in:
Seconds
Minutes
Hours
Fractional units

### 4.3 — Define Partial Time Periods
Determine how the game handles incomplete periods.
Example:
37 minutes and 42 seconds.

### 4.4 — Define Time Rounding
Determine whether calculations round:
Up
Down
To nearest
Not at all

### 4.5 — Define Minimum Calculable Time
Determine the smallest meaningful elapsed-time interval.

### 4.6 — Define Maximum Calculable Time
Determine whether there is a maximum elapsed period that can be processed at once.

### 4.7 — Define Multi-System Time Calculations
Determine how elapsed time is supplied to systems such as:
Hunger
Stamina
Mana
Actions
Rest
Crafting

### 4.8 — Create Elapsed-Time Examples
Create standardized examples for testing.

### 4.9 — Document Elapsed-Time Rules
Document the finalized calculations.

## Epic 4 Deliverable
A precise and repeatable method for calculating elapsed real-world time.
