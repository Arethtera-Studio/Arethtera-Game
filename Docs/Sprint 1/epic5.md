# Epic 5 - Define start/end timestamps for actions

## Objective: 
Establish how actions interact with the time system.

## Issues

### 5.1 — Define Action Start Timestamp
Determine when an action receives its official start timestamp.

### 5.2 — Define Action End Timestamp
Determine when an action receives its official end timestamp.

### 5.3 — Define Expected Action Duration
Determine how an action's expected duration is represented.

### 5.4 — Define Completed Actions
Determine how the system identifies an action that has completed.

### 5.5 — Define Interrupted Actions
Determine how an interrupted action's timestamps are handled.

### 5.6 — Define Cancelled Actions
Determine how cancelled actions are timestamped.

### 5.7 — Define Actions With No Fixed Duration
Determine how actions such as continuous gathering or exploration are represented.

### 5.8 — Define Action Timestamp Persistence
Determine how action timestamps are saved when the player logs out.

### 5.9 — Document Action Timestamp Rules

## Epic 5 Deliverable
Every time-dependent action has a defined relationship with the game's clock.
